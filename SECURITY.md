# Політика безпеки

Дякуємо, що допомагаєте тримати `waitforit-team-marketplace` та його користувачів
у безпеці. Оскільки плагіни Claude Code можуть виконувати команди, читати файли та
звертатися до зовнішніх сервісів, ми ставимося до повідомлень про вразливості
серйозно.

## Що вважається вразливістю

- Виконання довільного коду чи команд через плагін поза очікуваним сценарієм.
- Витік або ексфільтрація секретів, токенів, змінних середовища чи вмісту файлів.
- Шкідливий або скомпрометований `source` плагіна (git/npm), що підмінює очікуваний код.
- Підвищення привілеїв, обхід пісочниці чи системи дозволів Claude Code.
- Вразливі чи скомпрометовані залежності, які постачаються разом із плагіном.

## Як повідомити

**Не створюйте публічних GitHub issues для вразливостей безпеки.** Публічне
розкриття до випуску виправлення наражає користувачів на ризик.

Натомість оберіть один із приватних каналів:

1. **GitHub Security Advisory (бажано):** відкрийте приватний звіт на вкладці
   **Security → Report a vulnerability** репозиторію:
   <https://github.com/alex-andrushok/waitforit-team-marketplace/security/advisories/new>
2. **Email:** надішліть лист на [andrushoka@gmail.com](mailto:andrushoka@gmail.com)
   з темою, що починається на `[SECURITY]`.

### Що додати у звіт

- Який плагін і яка версія (або git-SHA) зачеплені.
- Тип вразливості та її потенційний вплив.
- Покрокові інструкції для відтворення (proof-of-concept, якщо можливо).
- Будь-які логи, скриншоти чи конфігурацію, що допоможуть діагностиці.
- Як з вами зв'язатися для уточнень.

## Чого очікувати

| Етап                            | Орієнтовний термін        |
| ------------------------------- | ------------------------- |
| Підтвердження отримання звіту   | протягом 48 годин         |
| Початкова оцінка та тріаж       | протягом 5 робочих днів   |
| Випуск виправлення (за валідації) | за домовленістю, залежно від складності |

Ми триматимемо вас у курсі прогресу, узгодимо дату скоординованого розкриття та
відзначимо ваш внесок у нотатках до релізу, якщо ви не проти.

## Відповідальне розкриття

Будь ласка, дайте нам розумний час на випуск виправлення, перш ніж розкривати
деталі публічно. Ми не вживатимемо заходів проти дослідників, які діють
добросовісно, дотримуються цієї політики та уникають порушення приватності,
знищення даних чи переривання роботи сервісів.

## Підтримувані версії

Виправлення безпеки виходять для останньої версії кожного плагіна в `main`.
Закріплюйте плагіни на конкретних версіях лише тоді, коли розумієте наслідки для
безпеки, і регулярно оновлюйтеся.
